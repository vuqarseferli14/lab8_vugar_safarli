		def greet(name, greeting="Salam"):
			print(greeting + ", " + name + "!")
		greet("Aysel")
		greet("Kamran", "Xosh gəldin")
		greet(greeting="Sabahınız xeyir", name="Nigar")
	output:
		Salam, Aysel!
		Xosh gəldin, Kamran!
		Sabahınız xeyir, Nigar!
	report:
		1st call (greet("Aysel")):
			we only write one word ("Aysel"). Python automatically puts this into the first box (name). Because we didn't write a second word, it uses the default word "Salam".
		2nd call (greet("Kamran", "Xosh gəldin")):
			we write two words the first word goes to name ("Kamran"), and the second word goes to greeting ("Xosh gəldin"). It uses instead of the default "Salam".
		3rd call (greet(greeting="Sabahınız xeyir", name="Nigar")):
			Python understands that name is Nigar and greeting is Sabahınız xeyir.

def average(*numbers):
    if len(numbers) == 0:
        return 0
    return sum(numbers) / len(numbers)
